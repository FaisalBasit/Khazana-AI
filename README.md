# Khazana AI

Khazana AI is an AI-focused web application project built with a modern TypeScript frontend stack.

## Overview

The project uses Vite and a component-based frontend architecture with TanStack tooling, React Query, Radix UI components, Tailwind CSS, and related TypeScript libraries.

## Technology

- TypeScript
- Vite
- TanStack
- React Query
- Radix UI
- Tailwind CSS
- ESLint and Prettier

## Development

Install dependencies and run the Vite development server using the project's package scripts.
